Complete Pipeline & What To Do

Step-by-step guide from smart contract deployment to using the DApp

01
📋
Open Remix IDE
Go to remix.ethereum.org → New file → Name it VehicleRegistry.sol → Paste the smart contract code
02
⚙️
Compile Contract
Click Solidity Compiler tab → Select version 0.8.19 → Click Compile VehicleRegistry.sol → Check for no errors
03
🦊
Deploy via MetaMask
Click Deploy & Run tab → Environment: Injected Provider - MetaMask → Switch to Sepolia Testnet → Click Deploy → Confirm in MetaMask
04
⛓️
Configure & Use
Copy the deployed address from Remix → Paste into app.js line 13 as CONTRACT_ADDRESS → Refresh this page → All features unlock!
